## ✨ Key Features

- 🔍 **Price Checker & Live Stock**: Real-time barcode lookup with location-based live stock availability and pricing.
- 🏷️ **Labels & Tags Printing**: Direct SMB network printing for Zebra / TSC thermal printers with Arabic & English text support.
- 📦 **Stock Take Counting**: High-speed warehouse barcode scanning with audit logs and CSV export.
- 🎨 **Promo Poster Generator**: Instant A4 & Shelf promo poster generation with multi-theme support (Ramadan, Clearance, Back to School, Summer).
- ⚡ **Offline First**: Fast embedded SQLite database with automatic Head Office OData background sync.

---

## 💻 System Requirements

- **Operating System**: Windows 10 or Windows 11 (64-bit)
- **RAM**: 4 GB minimum (8 GB recommended)
- **Network**: Local Network / Wi-Fi (for SMB thermal printing and OData sync)

## 🚀 How to Run

### Option A: Windows Installer (`.msi`)
1. Download `StockTake-1.0.4.msi`.
2. Double-click the installer and follow the setup wizard.
3. Launch **StockTake** from your Desktop shortcut or Start Menu.

### Option B: Portable ZIP (`.zip`)
1. Download `StockTake-Portable.zip`.
2. Right-click and select **Extract All...**.
3. Open the extracted folder and run **`StockTake.exe`**.
